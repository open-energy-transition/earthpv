# A blog for EarthPV

EarthPV now has a blog. It is where recalibrations, mapping campaigns and method
dead-ends get written up while they are still fresh, before they harden into the
reference docs.

<!-- more -->

## Why

The [reference docs](../../how-it-works.md) describe the pipeline as it stands
today. [Experiments](../../experiments.md) is the dated register of what was
tried. Neither is a good home for the running commentary in between: "the Best
estimate moved 4% overnight because three peri-urban quadrats came in", "this
week's random-cell validation sat under 2019 imagery again", "here is why the
out-of-domain AND-gate got dropped from the atlas". That commentary is useful,
and it belongs somewhere durable and public.

So: short posts, written as things happen, cross-linked into the methods pages
where the settled version lives.

## What to expect here

- **Method notes** -- what a calibration change did to the headline number and
  why, written the day it happened.
- **Field reports** -- notes from the LUMS mapping interns: what a quadrat in a
  new landscape looked like, what the imagery would and would not support.
- **Results** -- when a country gets its first atlas, or a number moves enough to
  be worth flagging.
- **Announcements** -- releases, new datasets, programme news.

## Contributing

The blog is open. If you map for this project, run the pipeline somewhere new, or
have a critique of a method worth writing down, you can publish it here. Open a
pull request adding a Markdown file under `docs/blog/posts/`, or
[open an issue](https://github.com/open-energy-transition/earthpv/issues) first if
you would rather talk it through. Full instructions are on
[Contribute a post](../contributing.md#how-to-add-a-post).
